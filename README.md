# WriteWise AI – AI Writing Assistant

## Project Overview

WriteWise AI is an AI-powered writing assistant developed using Python and the Google Gemini API. It helps users generate different types of creative and professional content through customized prompt templates.

## Features

### 1. Code Explanation
Explains programming code in a simple and understandable manner, helping users learn and understand code.

### 2. Blog Writing
Generates informative and engaging blog content based on user-provided topics.

### 3. Social Media Post Generation
Creates attractive and engaging content for social media platforms.

### 4. Poem Writing
Generates creative poems based on user-provided topics, ideas and themes.

### 5. Song Lyrics Generation
Creates original song lyrics based on user-provided themes and prompts.

### 6. Email Drafting
Generates professional and personalized emails for different purposes.

## Technologies Used

- Python
- Streamlit
- Google Gemini API

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/AnuPrizillaS/WriteWise-AI.git
```

### 2. Navigate to the Project Directory

```bash
cd WriteWise-AI
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure API Key

Configure your Google Gemini API key securely using environment variables.

### 5. Run the Application

```bash
streamlit run app.py
```

## Project Structure

- `app.py` – Main application code
- `requirements.txt` – Required Python dependencies
- `README.md` – Project documentation
